# Security Policy

## Reporting a Vulnerability

Email [Jorge Martinez](mailto:contact@jorgemartinez.space) to report a
vulnerability. Keep vulnerability details out of public issues and pull
requests until a fix is available.

Include:

- The affected version, branch, or commit.
- The source file or generated page where the problem occurs.
- The configuration and steps needed to reproduce it.
- The potential impact and how someone could exploit the issue.

Remove credentials and private data from any examples or logs you send.

.. _examples:

Examples
########

Run the ISA atmosphere, Monte Carlo π, and projectile motion examples below.
Each script uses NumPy for calculations and Matplotlib for plots.
These are executable notebook demonstrations, not a supported numerical API.
Importing a script also runs its top-level calculations and plotting code.
